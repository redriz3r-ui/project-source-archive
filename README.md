# Project Source Archive

Sanitized source snapshots of 21 personal software and hardware projects. Each project lives in its own folder and retains its own documentation and any existing license.

These are development snapshots, not a collection of production-ready releases. Read each project’s PUBLICATION.md for limitations. Local credentials, private settings, real account databases, personal media, dependencies, models and selected assets are omitted. A snapshot may require replacement assets before it runs. No new open-source license is granted for folders without a license.
