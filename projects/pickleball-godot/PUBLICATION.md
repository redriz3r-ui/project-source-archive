# Publication notes

Pickleball Godot game is being preserved as a public-source candidate.

Current scope: Godot scenes/scripts and sprite assets exist.

Preparation still required: Verify the game runs, add README/gameplay demo/license and asset credits. Prefer this source folder to PickleBall_iOSExport.

Some demos need replacement assets before they run. Existing validation documents describe earlier checks and have not been rerun for this export.
