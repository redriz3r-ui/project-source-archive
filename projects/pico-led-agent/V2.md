# Galactic Unicorn Agent v2

## What is running

The Pico 2 W now runs a versioned RGB scene engine designed for its complete
53×11 display. The Mac turns natural language into a validated scene document;
the Pico accepts that document once and plays it autonomously.

```text
prompt → deterministic interpreter → validated scene → USB or Wi-Fi → Pico queue → RGB renderer
                                      ↘ Mac preview / frame stream ↗
```

The original startup file is retained locally in `work/device_backup/main.py`.
Pimoroni's factory launcher remains on the Pico as `main.factory.py` from the
initial installation.

## Use it

Rich v2 command over USB:

```bash
.venv/bin/pico-led --v2 --port /dev/cu.usbmodem1101 \
  "make a dim cyberpunk city with amber windows, slow purple rain, blue lightning, then scroll ROB'S LAB in hot pink"
```

Preview the identical 53×11 scene dimensions on the Mac:

```bash
.venv/bin/pico-led --preview "ocean waves and stars"
```

Create an interactive browser preview with play/pause and frame scrubbing:

```bash
.venv/bin/pico-led --web-preview work/preview.html "ocean waves and stars"
open work/preview.html
```

Inspect the connected runtime:

```bash
.venv/bin/pico-led --status --port /dev/cu.usbmodem1101
.venv/bin/pico-led --capabilities --port /dev/cu.usbmodem1101
```

Save and replay a scene:

```bash
.venv/bin/pico-led --save night-drive "dim cyberpunk city and purple rain"
.venv/bin/pico-led --preset night-drive --port /dev/cu.usbmodem1101
```

Old commands remain compatible:

```bash
.venv/bin/pico-led --port /dev/cu.usbmodem1101 "make rain"
```

Language modifiers include `dim`, `bright`, `slow`, `fast`, `once`, `urgent`,
named colours, named palettes, transition names, and expiry such as
`for 2 minutes`.

## Scene model

A scene contains ordered steps. Each step contains composited effect layers.
Layers have an effect, palette, speed, intensity, opacity and blend mode.

Supported effects: rain, snow, fire, plasma, noise, stars, fireflies, particles,
comet, waves, scanner, city, text, icon, heart, eyes, lightning and spectrum.

Supported transitions: cut, fade, wipe, dissolve and glitch.

Supported blends: replace, alpha, add and max.

Limits are enforced on both Mac and Pico: 32 steps, 16 layers per step, bounded
speeds/intensities, safe brightness, 32 KiB messages and exactly 583 pixels per
RGB frame.

## Physical controls

- Brightness buttons adjust the safe capped brightness.
- A selects ocean rain.
- B selects fire.
- C selects eyes.
- D selects a time-varying surprise effect.
- Sleep clears the display and stops queued scenes.
- Ambient light smoothly adjusts brightness when enabled.

Sound cues are disabled by default. Set `SOUND_CUES=True` only if a brief scene
start tone is desired.

## Wi-Fi

USB remains the recovery path. Configure Wi-Fi privately without putting the
password into this repository or command history:

```bash
.venv/bin/python tools/configure_wifi.py --port /dev/cu.usbmodem1101
```

The password is entered without echo, uploaded through a mode-600 temporary
file, and immediately removed from the Mac. The generated API token is printed
once and should be saved in a password manager.

Then use:

```bash
.venv/bin/pico-led --v2 --transport wifi --host PICO_IP --token TOKEN "ocean waves"
.venv/bin/pico-led --v2 --transport websocket --host PICO_IP --token TOKEN "ocean waves"
```

The Pico exposes authenticated `POST /command`, `GET /status`,
`GET /capabilities`, and a WebSocket endpoint at `/ws`. It does not expose
itself to the public internet; keep it on a trusted local network.

## Audio and streamed media

`led_agent.audio.AudioAnalyzer` performs spectrum and beat analysis on the Mac.
`SpectrumRenderer` converts the analysis into 53×11 frames, and
`FrameStreamer` sends rate-limited RLE-compressed RGB frames. Live microphone
capture is optional:

```bash
python -m pip install -e '.[audio]'
.venv/bin/pico-led --audio-reactive 30 --port /dev/cu.usbmodem1101
```

Stream an image or animated GIF with original frame timing:

```bash
.venv/bin/pico-led --stream-media animation.gif --media-loops 2 --port /dev/cu.usbmodem1101
```

The protocol also accepts any other source of 53×11 canvases, enabling generated
pixel art, decoded GIF frames, clipboard imagery and future real-time inputs.

## Safe update and recovery

Preview an update:

```bash
.venv/bin/python tools/deploy.py install --port /dev/cu.usbmodem1101 --dry-run
```

Install and verify:

```bash
.venv/bin/python tools/deploy.py install --port /dev/cu.usbmodem1101
.venv/bin/python -c "from led_agent.transports import SerialTransport; print(SerialTransport('/dev/cu.usbmodem1101').send({'v':2,'cmd':'capabilities'}))"
```

Restore the backed-up startup:

```bash
.venv/bin/python tools/deploy.py restore --port /dev/cu.usbmodem1101
```

The watchdog restarts the Pico if its main loop becomes unresponsive.
