# Publication notes

Pico W LED Agent is being preserved as a public-source candidate.

Current scope: Natural-language-style deterministic command parser, serial transport and terminal simulator, plus Galactic Unicorn V2 work.

Preparation still required: Choose how it relates to Galactic WLED rather than publishing several overlapping LED repos. Add license, keep real Wi-Fi settings private, and include simulator instructions.

This source export deliberately omits local credentials, personal configurations, caches, installed dependencies, local datasets and selected media/models. Some demos need replacement assets before they run. Existing validation documents describe earlier checks and have not been rerun for this export. No new open-source license is granted by this export; see any existing project license.
