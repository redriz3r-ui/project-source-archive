# Publication notes

Musicgoo is being preserved as a public-source candidate.

Current scope: Godot scripts/scenes and many MP3 files.

Preparation still required: Review/remove bundled songs and sound effects unless cleared for sharing, then document gameplay and add license.

This source export deliberately omits local credentials, personal configurations, caches, installed dependencies, local datasets and selected media/models. Some demos need replacement assets before they run. Existing validation documents describe earlier checks and have not been rerun for this export. No new open-source license is granted by this export; see any existing project license.

An embedded commercial MP3 was removed from nightsky.tscn in this public copy. Original media remains local; supply your own shareable soundtrack.
