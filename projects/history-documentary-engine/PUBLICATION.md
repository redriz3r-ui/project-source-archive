# Publication notes

History Documentary Engine is being preserved as a public-source candidate.

Current scope: Manifest-driven Remotion documentary renderer with narration/caption/media tooling. The source tree is more developed than its old outputs copy.

Preparation still required: Exclude caches, renders, models and optional vendored checkouts. Review asset provenance and third-party notices, select a license for original code, and demonstrate a small deterministic render. Automated token patterns also matched vendored configs; those are unverified candidates, not confirmed credentials.

This source export deliberately omits local credentials, personal configurations, caches, installed dependencies, local datasets and selected media/models. Some demos need replacement assets before they run. Existing validation documents describe earlier checks and have not been rerun for this export.
