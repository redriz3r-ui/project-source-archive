Privacy & scope

Preferences and selected handle stay in chrome.storage.local. There is no account, analytics, browsing history log, stream fetching or recording. The connected build requests Chaturbate’s official online-room feed directly, using this device’s public IP for regional availability. The selected handle is matched locally; it is not sent as a search query. Only the selected room’s status is retained. No login cookie or password is used by the API client. The simulator makes no status requests.

An allowed room may contain recommendations, chat or thumbnails. LiveLock restricts navigation; it does not remove all content inside an allowed page or bypass login and age checks. Relocking is best effort: alarms can be delayed during sleep and session rules have no automatic expiry.
