# Game Jam Project

A game created during a game jam exercise using Godot Engine.

## Setup Instructions

1. Make sure you have Godot Engine installed (version 4.x recommended)
2. Clone this repository
3. Open the project in Godot Engine
4. Run the project by pressing F5 or clicking the "Play" button

## Project Structure

- `scenes/` - Contains all game scenes
- `scripts/` - Contains all GDScript files
- `assets/` - Contains all game assets (sprites, sounds, etc.)
- `ui/` - Contains UI-related scenes and scripts

## Development Guidelines

- Keep code modular and reusable
- Comment important code sections
- Use meaningful variable and function names
- Follow Godot's naming conventions
