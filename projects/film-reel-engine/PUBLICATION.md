# Publication notes

Film Reel Engine is being preserved as a public-source candidate.

Current scope: Local shot indexing, analysis, clip selection and browser controls.

Preparation still required: Exclude the entire projects/ tree: it currently includes movie stills, clips and a roughly 299 MB analysis proxy. Use a generated or otherwise shareable demo, add license, and remove personal absolute paths. Compare other reel engines before selecting the canonical project.

This source export deliberately omits local credentials, personal configurations, caches, installed dependencies, local datasets and selected media/models. Some demos need replacement assets before they run. Existing validation documents describe earlier checks and have not been rerun for this export. No new open-source license is granted by this export; see any existing project license.
