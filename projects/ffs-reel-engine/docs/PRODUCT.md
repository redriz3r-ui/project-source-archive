# Product direction

FFS Reel Engine is an editorial film-analysis system, not a one-film editor or
generic clip generator. Each recipe uses locally supplied, licensed footage as
evidence for original FFS commentary. Before Sunrise is the pilot film. The
governing principle is: **Don't post the movie. Post an idea about the movie.**

## Recipe 01 — Mood Montage

1. Link a movie without copying or transcribing it.
2. Generate a fast visual overview with timestamped thumbnails.
3. Let the editor choose and order 6–10 moments.
4. Adjust each shot's start and duration and set vertical framing.
5. Export a muted 9:16 montage for human review.
