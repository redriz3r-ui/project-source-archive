# Publication notes

Pico Hand Piano is being preserved as a public-source candidate.

Current scope: Saved hand-distance musical controller with wiring notes and generated piano samples.

Preparation still required: Replace the transcribed commercial melody with an original/publicly shareable example, make the Python launcher portable, add license and a short demo.

This source export deliberately omits local credentials, personal configurations, caches, installed dependencies, local datasets and selected media/models. Some demos need replacement assets before they run. Existing validation documents describe earlier checks and have not been rerun for this export. No new open-source license is granted by this export; see any existing project license.

The seven generated WAV note samples are omitted from the public source export. Restore or synthesize local samples under song_piano/ before using the audio player.
