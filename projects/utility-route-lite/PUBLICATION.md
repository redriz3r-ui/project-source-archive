# Publication notes

Utility Route Lite is being preserved as a public-source candidate.

Current scope: QGIS network-builder implementation with GPL text and source/tests.

Preparation still required: Keep the implemented scope explicit: four processing tasks and the reviewer are unimplemented, and the README says routing/batch/export fixtures remain red. Do not present it as a working routing product.

This source export deliberately omits local credentials, personal configurations, caches, installed dependencies, local datasets and selected media/models. Some demos need replacement assets before they run. Existing validation documents describe earlier checks and have not been rerun for this export. No new open-source license is granted by this export; see any existing project license.

The generated examples/fixtures/v1/benchmark_1000.json benchmark fixture is omitted from the public source export. Retain or regenerate it locally for benchmark tests.
