# Tool 01 — Network Builder

Network Builder reads one existing LineString/MultiLineString feature source without starting an edit transaction. It requires declared `SOURCE_CRS`, a projected meter `NETWORK_CRS`, a persistent `LAYER_KEY`, a unique string `FEATURE_KEY_FIELD`, and a versioned local `RULE_PROFILE` JSON. For `EXPLICIT_JUNCTIONS`, pass a versioned `JUNCTIONS_JSON` with exact source-part anchors and directed transitions; for `GEOMETRIC_ENDPOINT_ONLY`, leave it absent. Existing destinations are rejected. Outputs are a graph JSON and a separate GeoPackage `qa_issues` layer.

The graph records original vertices, stable source feature and zero-based multipart part references, transformed 2D vertices, eligible/direction state, virtual split intervals, directed transitions, hashes, measurement method, QA issues and a derived build summary. `source_to_edges` identifies every derived edge for each source part. The summary's weak component IDs use eligible edges and declared transitions. Geometric endpoint connectivity is labeled `NOT_ASSET_VERIFIED`; explicit junction connectivity is labeled `DECLARED_TRANSITIONS_NOT_FIELD_VERIFIED`.

Crossings, shared interior points and endpoints merely near one another never create connections. QA reports undeclared crossings, interior touches, overlap, near misses, dangles, disconnected components, rule uncertainty and opted-in Z/M projection. The source is never moved or repaired. Unknown edge status/direction remains `UNKNOWN` and is excluded from eligible components; unsupported rules and malformed junctions fail the job. A declared interior member creates virtual splits while preserving each clipped source vertex sequence and original part reference. Exact equality is checked after the declared CRS transformation.

Length and near-miss distances are measured in meters with `QgsDistanceArea` in the QGIS adapter. Pure Python mode is only for already projected metric coordinates under an explicit `ellipsoid: NONE` profile; it does not stand in for geographic CRS processing. The builder's pairwise topology QA has a five-million candidate guard and returns `LIMIT_EXCEEDED` rather than silently omitting a scan. At present it is tested on small fixtures and a 1,000-edge chain; larger dense networks need performance evidence.

Run `python3 -m unittest discover -s tests -p 'test_builder_core.py' -v` for pure core cases. Run `bash scripts/run_qgis_scaffold_macos.sh /Applications/QGIS-final-4_2_3.app tests/qgis_builder.py` for offscreen Processing, GeoPackage, source immutability and geographic measurement checks. Installation in a live QGIS Plugin Manager remains a separate release gate. Smart Router, Inspector, Reviewer, Batch and Packager remain unimplemented.
