# Product decisions

Date: 2026-10-16. These are charter-level decisions; architecture may refine schemas and implementation after recording a reason and test impact here.

| ID | Decision | Reason and consequence |
| --- | --- | --- |
| D-001 | Deliver one QGIS 4.2+ / Qt6 plugin with five Processing algorithms and a Route Reviewer dock. | One installable product and reusable services support independent tools and model use. Check actual QGIS 4.2 APIs before implementation. |
| D-002 | Launch claim is a connected, inspectable **proposed** pathway route, subject to declared connectivity rules. | Geometric endpoint adjacency is a graph hypothesis, never proof of physical asset connectivity. Every result must show policy and verification status. |
| D-003 | Support `GEOMETRIC_ENDPOINT_ONLY` and `EXPLICIT_JUNCTIONS`; never auto-node crossings or silently repair. | Utility corridors can cross without connecting. Unknown transitions fail closed and produce QA. |
| D-004 | Optimize only shortest eligible 2D distance in v1.0. | A testable objective with nonnegative meter lengths. Cost weights/alternatives are v1.1 candidates unless separately implemented and tested. |
| D-005 | Source layers are read-only; outputs are separate, local and provenance-rich. | Protect authoritative data and make route claims inspectable/reproducible. |
| D-006 | Declare CRS and calculate length in meters using verified PyQGIS measurement or transformation; disclose Z/M reduction. | Map-unit assumptions and 3D implications would mislead users. |
| D-007 | Prefer original pure-Python graph logic plus thin QGIS adapters; use existing GitHub projects for concepts only pending file-level audit. | Maintains portability/testability and avoids premature license/behavior inheritance. Proposed license is GPL-3.0-or-later, contingent on compatibility review before code import. |
| D-008 | No mandatory external package, service, API key, telemetry or unauthorized sample data. | A locally usable plugin with controlled data disclosure. |
| D-009 | v1.0 release is NO-GO without recorded clean-install, functional, safety, audit and package evidence. | The prompt pack is a plan, not proof of implementation or certification. |
| D-010 | Following Prompt 02, use original connectivity and transition-aware routing services; native graph construction is not the policy authority. | QGIS 4.2.3 probes confirm that shared interior vertices connect without asset evidence. Preserve native geometry/CRS/writer/dock APIs; freeze explicit connection, snap, measurement and provenance rules before implementation. See [audit](audits/PRIOR_ART.md). |
| D-011 | No third-party source copy is approved by the audit; GPL-3.0-or-later remains the proposed license. | Reviewed GPL grants are compatible in principle, subject to file/dependency attribution; cookbook-derived code and unaudited assets require separate clearance. Conceptual inspiration does not introduce a runtime dependency. |
| D-012 | Freeze `schema_version=1.0.0`, provider `utilityroutelite`, five algorithm IDs, GeoPackage fields, status codes and report files in `docs/contract/v1.json`. | Interface drift would break Processing models, saved results and exports. Changes require a new numbered decision, migration plan and acceptance tests. |
| D-013 | Use exact normalized transformed 2D equality for geometric part endpoints; explicit junction members and directed transitions are the only cross-part connections in `EXPLICIT_JUNCTIONS`. | Closes prior-art blocker 1 by excluding shared interior vertices and undocumented joins. Intrinsic same-part continuity is allowed at virtual splits. Near misses remain QA. |
| D-014 | Snap requests to one eligible physical edge at a time, with measured meter offset and deterministic tie rules; remeasure same-edge partial geometry. | Closes prior-art blocker 2. An offset is disclosed, never emitted as an invented utility segment. |
| D-015 | Require a projected meter `network_crs`, explicit input CRSs, QGIS distance measurement and an opt-in before reducing Z/M to 2D. | Closes prior-art blocker 3 as a design rule. Real geographic/foot transformations and error paths remain implementation test obligations. |
| D-016 | Require durable caller-supplied layer/feature keys plus content fingerprints and result/review digests; source-native FIDs are diagnostic only. | Closes prior-art blocker 4 as a contract without writing UUIDs to authoritative layers. |
| D-017 | Fail closed on unknown eligibility and transitions; stage outputs, stream batch rows, cap graph/request size, and mark stale/partial/canceled states explicitly. | Closes prior-art blocker 5 at design level. Security and failure behavior remain test gates. |
| D-018 | In response to the Network Builder deliverable, include optional `build_summary` diagnostic metadata in graph JSON: policy/verification label, edge/node/component counts, stable node-to-component IDs and an unambiguous source-part-to-edge list. | Prompt 06 explicitly requires a machine-readable graph summary and component IDs. Existing required v1 graph fields and routing semantics stay unchanged; `graph_digest` continues to cover topology/provenance rather than the derived summary. Readers may ignore this additive metadata. Validate or revise this contract clarification before release and add round-trip reader tests. |

The architecture choices above are frozen design decisions. Their implementation and release evidence remain open in [ACCEPTANCE_MATRIX.md](ACCEPTANCE_MATRIX.md) and [BUILD_STATUS.md](BUILD_STATUS.md).

## Round 2 correctness decisions — pending architect / independent review

- **D-019:** Register the already-emitted `ID_COLLISION` build error in the pre-release v1 contract and add a registry regression. This reconciles the implementation and its existing collision tests; no success schema, algorithm ID or behavior is changed. Requires architect acceptance before release.
- **D-020:** Reuse `QgsCoordinateReferenceSystem` for arbitrary CRS validation through a small lazy QGIS adapter. Keep the known EPSG:3857 pure synthetic path; reject other definitions when QGIS is unavailable. Remove WKT regex parsing and validate the target even when callbacks are supplied. Public function parameters remain unchanged. Requires architect review of this explicit pure-runtime boundary.
- **D-021:** Publish each closed Builder output with `os.link` from a temporary directory on its destination filesystem. Linking fails if a destination exists, including a concurrent or dangling-symlink entry. Unsupported hard-link filesystems fail safely; no overwriting fallback. Rollback removes only published paths still referencing the staged inode. Two separate paths cannot promise process-crash atomicity; cancellation and ordinary exceptions roll back owned outputs. Requires independent verification, not release approval.
