# Prioritized technical risks

Date: 2026-10-16. All risks below are open for implementation; the audit establishes evidence and mitigations, not closure. See [PRIOR_ART.md](PRIOR_ART.md) for pinned sources, license qualifications and executed probes. This extends the preserved charter baseline in `docs/RISKS.md`.

| Priority / severity | Risk and evidence | Mitigation and closure test | Owner / gate |
| --- | --- | --- | --- |
| R-01 — Critical | **Invented connectivity.** Network Topology nodes X/T intersections and extends dangles. QGIS native director merges coincident interior vertices; reproduced on 4.2.3. | Original graph construction with explicit policies. Fixtures must keep X crossings, T interior touches, overlapping lines, shared interior vertices and near misses separate unless a declared transition permits connection. Test endpoint-only and explicit-junction policies independently. | Architect + Network Builder; architecture blocker 1 and graph audit. |
| R-02 — Critical | **Illegal turns or unknown constraints accepted.** Ordinary node-based Dijkstra cannot express every incoming-edge-dependent transition. Native default direction can permit travel for unmatched attributes. | Define direction/eligibility vocabulary, reject unsupported rules, fail closed on unknown values, and search an expanded transition state where required. Fixture: shortest unrestricted path is forbidden, longer eligible route must win; no eligible route produces a reason. | Architect + Smart Router; architecture blockers 1/5 and shortest-path audit. |
| R-03 — High | **Snap attachment invents a utility leg or joins separate edges.** QNEAT includes entry/exit legs; native graph construction globally shares vertices. | Metric snap tolerance, deterministic eligible candidates, edge-local temporary splits and separate snap-offset reporting. Test same-edge, reversed one-way, coincident candidates, outside-tolerance, crossing and multiple-request cases; preserve intermediate source vertices. | Architect + Router; architecture blocker 2. |
| R-04 — High | **Incorrect units, failed transformations or silent dimensional loss.** Upstream topology helpers use map units; native director source can continue after a measurement exception; `asPolyline()` discards Z/M. | Explicit CRS/measurement method, validated transformations, finite positive weights, surfaced errors, and declared 2D policy. Test geographic, meter and foot CRSs, partial curved polyline length, Z/M, multipart, invalid/empty and zero-length inputs. Local meter/Z/M probes reduce API uncertainty only. | Architect + QGIS adapter; architecture blocker 3 and integration. |
| R-05 — High | **Unstable provenance and stale review.** Layer IDs/FIDs are not guaranteed durable across reload/export; borrowed UUID-writing behavior would violate source immutability. Workspace currently lacks Git history. | Durable source identity plus snapshot/version fingerprints and stable feature/part references; invalidate stale route/review/config combinations. Test reload/reorder/rebuild, duplicate IDs and changed geometry with identical FID. Record a real source revision when repository history is established. | Architect + Builder/Reviewer/Packager; architecture blocker 4. |
| R-06 — High | **False compatibility confidence.** Packaging-only CI can be green; import-skipped tests do not validate QGIS. FiberQ's real CI targets 4.0 rather than 4.2. | Require exact runtime version in logs, no silent skipped integration gate, minimum 4.2 and declared platform testing, actual registration/unload and fresh-profile ZIP installation. Eight local 4.2.3 API probes passed; plugin/GUI integration remains UNVERIFIED. | Scaffold + integration + release gate. |
| R-07 — High | **Third-party license/provenance inheritance.** QNEAT project/header minimum versions differ; On-the-Fly names cookbook-derived code; images and fixtures have not been cleared. | Use original code and installed APIs. Before any copy, record revision/file grants, attribution, dependencies and selected GPL terms. Resolve cookbook grant separately; never assume a GPL repository badge clears all assets. Include complete chosen GPL text at scaffold stage. | Prior-art/import review + final license audit. |
| R-08 — High | **Unsafe or misleading exports.** HTML/CSV injection, path traversal, credential-bearing layer URIs, overwrite and interrupted writes can harm recipients or misrepresent completion. | Allowlisted portable schema; exclude credentials/private paths; HTML escaping and formula-safe CSV; validate destination/source collision and symlinks; stage outputs and publish only on success. Test malicious attributes, same-as-source destination, permission failure, cancellation and full QGIS bundle round-trip. | Packager + security/release audit; architecture blocker 5. |
| R-09 — Medium | **Batch memory/runtime growth and partial failure loss.** All-pairs OD patterns do not directly fit supplied pair requests; graph reconstruction per row or quadratic near-miss checks can dominate. | Cache by source snapshot/profile, use a spatial index, bounded row processing and staged writes, deterministic errors and cancellation. Test two successes/one failure, malformed and duplicate IDs, cancellation and measured 1,000-pair benchmark. Publish actual environment/results, not a speed promise. | Batch + Inspector + integration; architecture blocker 5. |

Close a risk only with a linked code/test revision and actual result. The frozen architecture and data contract now specify responses to R-01 through R-05; their implementation risks remain open. Unresolved correctness, security, licensing or installation blockers prevent v1.0 release.
