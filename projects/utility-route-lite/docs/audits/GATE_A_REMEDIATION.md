# Gate A Network Builder remediation

Date: 2026-10-17. This is the implementation handoff for independent re-audit. **Gate A remains FAIL / NO-GO until the independent reviewer changes the verdict.** Smart Router and subsequent tools remain untouched. The [original audit](GRAPH_REVIEW.md) is the finding authority; this document records the engineering response. No Git commit was made because this workspace has no `.git` directory.

## Root causes, changes and regression evidence

All original failures were reproduced in the prior audit's saved [core](evidence/gate-a/core-regressions.txt) and [QGIS](evidence/gate-a/qgis-regressions.txt) logs before editing. The independent regression scripts were not weakened or skipped. After remediation they pass as shown below. The scripts write their generated JSON examples to `evidence/gate-a/`, so those example files now reflect the corrected implementation; the original failing logs remain preserved.

| Finding | Original failure and violated invariant | Root cause and implementation | Regression and result | Remaining risk |
| --- | --- | --- | --- | --- |
| GA-01 HIGH | Contradictory `has_z=False` with XYZ silently joined stacked XY lines; dimensional opt-in required. | Core now checks exact Boolean flags, uniform coordinate arity and flag/arity agreement before taking XY. It rejects unsupported input with `UNSUPPORTED_DIMENSION`, retains original ordinates with explicit opt-in and warns `Z_M_IGNORED`. `core/builder.py`; QGIS WKB adapter still supplies true dimensional flags. | Independent `test_false_dimension_flags_cannot_silently_connect_stacked_lines`; new `test_explicit_dimension_modes_and_mixed_arity`; QGIS Z/M/ZM test. All pass. | v1 graph is expressly 2D even after consent; field connectivity remains unverified. |
| GA-02 HIGH | Integer status 7→8 left snapshot hash unchanged; all selected raw values must affect provenance. | QGIS adapter stopped replacing non-string values with `None`. Core fingerprints tagged `null`, Boolean, integer, finite float and string values separately, while rule evaluation still maps unmatched types to UNKNOWN. Unsupported selected types fail explicitly. `qgis_adapters/builder.py`, `core/builder.py`. | Independent `test_raw_selected_attribute_change_invalidates_fingerprint`; new typed-value and attribute-change tests. All pass. | Date/time/binary/custom QVariant values are rejected until a versioned representation is specified. |
| GA-03 HIGH | Equivalent segment 0/fraction 1 and segment 1/fraction 0 produced different node/edge IDs; source-vertex anchor must be canonical. | Junction member position is normalized to the following segment's fraction 0 at interior vertices; fractions use float type. Duplicate detection remains by normalized source position. `core/builder.py`. | Independent `test_equivalent_vertex_anchor_has_stable_edge_ids`; source-order, JSON round-trip and attribute-ID tests. All pass. | The raw junction-document hash may differ for equivalent user documents; edge/node IDs are stable. |
| GA-04 HIGH | A declared junction at one XY suppressed unrelated crossings at that XY; QA may suppress only the declared member pair. | Validated transition rows now produce pair/location keys in transformed network coordinates. Spatial QA suppresses only those pairs, retaining warnings for nonmembers. `core/builder.py`. | Independent `test_nonmember_crossing_is_reported`; new transformed-junction-coordinate test. Both pass. | Pair-wise QA is exact-XY and inherits the declared CRS transformation's precision. |
| GA-05 HIGH | A bow-tie source part accepted an ambiguous interior junction despite required `INVALID_JUNCTION`. | Every declared member point is checked against all other segments of the same part. Ordinary adjacent-segment vertex representation is accepted; a second nonadjacent location is rejected. `core/builder.py`. | Independent `test_ambiguous_self_intersection_anchor_rejected` passes. | The check is linear in part segment count per declared member; very complex self-intersecting parts can still consume time. No approximate geometry repair is attempted. |
| GA-06 HIGH | Pure core treated EPSG:4326 degrees as meters; meter length requires validated metric context. | Without adapter measurement, core accepts identical planar metric CRS only through a conservative EPSG:3857 or projected Cartesian meter-axis check. The QGIS adapter continues full CRS validation, transformation and `QgsDistanceArea` measurement. `core/builder.py`. | Independent geographic-core rejection; new foot-WKT rejection; existing and QGIS geographic-source metric tests. All pass. | Standard-library pure mode cannot authoritatively parse all projected CRSs; ambiguous/unrecognized forms should be passed through the validated QGIS adapter. A false user CRS declaration cannot be discovered from geometry alone. |
| GA-07 HIGH | Already-canceled 10k generator fully consumed; late limits and P×E continuation scan. | Core checks cancellation before iteration and across feature, vertex, junction, edge, component, QA and serialization phases. Running source/derived limits fail before further allocation. Edges are indexed by source part for intrinsic continuation. QGIS adapter yields snapshots to core and checks each vertex. QA writer inserts in 1k batches; canceled staging/commit rolls back both output files and raises CANCELED. `core/builder.py`, `qgis_adapters/builder.py`, `processing/algorithms.py`. | Independent pre-cancel test; new mid-build cancellation and QGIS post-first-publish cancellation tests; 10k/50k bounded measurements. All pass. | Python sorting, hashing, and QGIS `writeAsVectorFormatV3` are not interruptible inside a single native call. Process termination or disk failure between two file commits can still leave a partial pair; release packaging needs transactional failure review. The 250k maximum was not stress tested. |
| GA-08 MEDIUM | Nonzero closed polyline produced a self-loop contrary to contract. | Core rejects equal transformed start/end before graph allocation. `core/builder.py`. | Independent `test_closed_self_loop_rejected` passes. | Legitimate ring corridors require a future explicit policy decision; this v1 contract excludes them. |
| GA-09 MEDIUM | Contact at both intermediate source vertices was invisible to QA. | Spatial QA classifies each contact against full source-part endpoints, reports interior/interior crossings and interior/end T touches, and deduplicates repeated segment-pair observations. No topology edges are added. `core/builder.py`. | Independent `test_crossing_at_interior_vertices_is_reported`; new T-at-intermediate-vertex test. Both pass. | QA intersection arithmetic uses exact transformed 2D coordinates; near interactions remain covered by separate near-miss rules rather than auto-joining. |
| GA-10 LOW | Hash collision could merge unrelated nodes or overwrite edge lookup despite collision-abort contract. | Core stores node/edge identity payloads and aborts with `ID_COLLISION` on distinct node payload reuse or any duplicate edge ID. `core/builder.py`. | New forced node and edge collision test passes. | No real SHA-256 collision was generated or claimed. |

The graph schema, Processing parameter names, IDs and source-layer read-only behavior remain as specified in [DATA_CONTRACT](../DATA_CONTRACT.md). Corrected source hashes and canonical anchor IDs necessarily change some output values from the defective build; existing saved graph artifacts should be rebuilt before later consumers use them. No third-party dependency was added.

The two scale runs were separate processes. Their measured times are environment observations, not release performance promises. The 50k run retained an in-memory graph and did not write GeoPackage output.

The broad command `python3 -m unittest discover -s tests -p 'test_*.py' -v` also ran and **failed**: 35 tests, 18 errors and one skip. All 18 errors come from the pre-existing `tests/fixture_adapter.py` `NotImplementedError` for not-yet-implemented graph/route/export fixture orchestration; they were present before this remediation and were left intact. The skip is PyQGIS availability in system Python; the same CRS integration tests passed under bundled QGIS Python. See the [full discovery log](evidence/gate-a-remediation/full-discovery.txt). The broader suite therefore cannot be called green, and later tool work remains out of scope.
