# Publication notes

Terrain Lab (HabitatGenes folder) is being preserved as a public-source candidate.

Current scope: TypeScript geospatial sandbox and terrain atlas with source-verification scripts.

Preparation still required: Add license and attribution/data provenance notes, review research/intake and public assets before including them, remove unrelated presentation drafts, and add a small reproducible demo.

This source export deliberately omits local credentials, personal configurations, caches, installed dependencies, local datasets and selected media/models. Some demos need replacement assets before they run. Existing validation documents describe earlier checks and have not been rerun for this export. No new open-source license is granted by this export; see any existing project license.
