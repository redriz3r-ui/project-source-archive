# Publication notes

SelfPleasure is being preserved as a public-source candidate.

Current scope: Local camera/device-control application with substantial tests and documentation.

Preparation still required: Keep the documented disabled real-device default and failed physical-stop limitation prominent. Exclude config.local*.json, local models and private captures/settings; publish only a clearly scoped development/simulator build until its documented release gates pass.

This source export deliberately omits local credentials, personal configurations, caches, installed dependencies, local datasets and selected media/models. Some demos need replacement assets before they run. Existing validation documents describe earlier checks and have not been rerun for this export. No new open-source license is granted by this export; see any existing project license.
